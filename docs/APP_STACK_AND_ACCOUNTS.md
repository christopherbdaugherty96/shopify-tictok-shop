# App Stack and Account Setup

This document lists the websites and apps needed to start the print-on-demand shirt business manually.

## Core Business Model

The business uses print-on-demand fulfillment:

1. You create or upload a shirt design.
2. You create product mockups.
3. You list the product online.
4. A customer buys the shirt.
5. The print-on-demand provider prints and ships the order.
6. You handle the brand, product decisions, marketing, customer communication, and tracking.

You do not hold inventory at the beginning.

## Required Accounts

### 1. Design Account

Use one free-first design tool:

- Canva
- Photopea
- Kittl free plan

Recommended starting choice: Canva free plan.

Purpose:
- create shirt graphics
- create social post images
- create simple logo/brand assets
- create promotional graphics

Setup steps:

1. Create account.
2. Create a folder for the brand.
3. Create subfolders for designs, mockups, ads, and social posts.
4. Export final shirt designs as PNG when possible.
5. Keep editable source files saved.

### 2. Print-On-Demand Account

Use one fulfillment provider first:

- Printify
- Printful

Recommended starting choice: Printify for low-cost testing, or Printful for a simpler polished experience.

Purpose:
- create product mockups
- connect products to Shopify
- print orders after purchase
- ship products to customers

Setup steps:

1. Create account.
2. Add business/store name.
3. Choose a shirt product.
4. Upload design.
5. Generate mockups.
6. Set product cost and variants.
7. Connect to Shopify later.

### 3. Storefront Account

Recommended first serious storefront: Shopify.

Purpose:
- product pages
- checkout
- payments
- order tracking
- customer emails
- storefront brand

Setup steps:

1. Create Shopify account.
2. Choose a free theme.
3. Add store name.
4. Add basic homepage text.
5. Add About page.
6. Add Contact page.
7. Add Shipping Policy.
8. Add Return Policy.
9. Add Privacy Policy.
10. Add Terms of Service.
11. Connect payment provider.
12. Connect Printify or Printful app.
13. Create the first product draft.
14. Review everything manually before publishing.

### 4. Payment Setup

Shopify payments usually require:

- legal name
- business name if available
- address
- bank account
- tax details
- payout setup
- identity verification if requested

Starting path:

1. Use Shopify Payments if eligible.
2. Add PayPal if available.
3. Connect bank account for payouts.
4. Confirm payout schedule.
5. Place a test order if Shopify allows test mode.

Important:

Payments must be set up before real customers can successfully buy.

### 5. Business Email

Start with a simple dedicated email.

Options:
- Gmail
- Outlook
- custom domain email later

Use it for:
- Shopify account
- Printify/Printful account
- customer support
- order notifications
- social accounts

Recommended format:

```txt
brandname@gmail.com
support@brandname.com later
```

### 6. Social Accounts

Start with:

- TikTok
- Instagram
- Facebook page/profile

Optional later:
- Pinterest
- YouTube Shorts

Purpose:
- post mockups
- post short videos
- test product interest
- drive traffic to product page
- build brand awareness

Setup steps:

1. Create account with business email.
2. Use same brand name across platforms if possible.
3. Add simple bio.
4. Add store link when available.
5. Save login information securely.
6. Post manually at first.

### 7. Tracking System

Use this repo first.

Trackers:

- `trackers/design_backlog.csv`
- `trackers/products.csv`
- `trackers/content_calendar.csv`
- `trackers/sales_pipeline.csv`

Optional later:
- Google Sheets
- Notion
- Airtable

Do not overcomplicate tracking at the start.

## Minimum App Stack

Use this minimum stack first:

```txt
Design: Canva free
Mockups/Fulfillment: Printify or Printful
Storefront: Shopify
Content editing: CapCut free + Canva free
Posting: TikTok + Instagram
Tracking: CSV files in this repo or Google Sheets
Email: Gmail
Payments: Shopify Payments + bank account
```

## Free-First Path

To spend the least money early:

1. Use Canva free for designs.
2. Use Printify/Printful mockups.
3. Create social posts first.
4. Test interest manually.
5. Only pay for Shopify when ready to take orders seriously.
6. Avoid paid ads until organic posts show interest.

## Paid Items To Expect Eventually

Likely costs later:

- Shopify monthly plan
- domain name
- sample shirt order
- upgraded design tools if needed
- paid ads later
- custom email later

Do not pay for everything on day one.
