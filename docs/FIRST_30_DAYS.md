# First 30 Days

This document explains the first realistic month of the business.

The goal is not perfection.

The goal is:
- launch
- consistency
- testing
- learning
- first sales
- understanding the workflow

## Week 1 — Foundation

### Goals

- Choose niche
- Create accounts
- Create first designs
- Understand the workflow

### Tasks

1. Read:
- `docs/START_HERE.md`
- `docs/STARTUP_GUIDE.md`
- `docs/PAYMENT_AND_FULFILLMENT.md`

2. Create accounts:
- Canva
- Printify or Printful
- TikTok
- Instagram
- Shopify when ready

3. Pick one niche.

4. Create 10 shirt ideas.

5. Create 1 to 3 shirt designs.

6. Create mockups.

7. Organize files.

### End Of Week Goal

Have:
- niche selected
- accounts created
- first mockups completed

## Week 2 — Store Setup

### Goals

- Build first storefront
- Create first listings
- Prepare posting workflow

### Tasks

1. Create Shopify store.

2. Connect Printify or Printful.

3. Create:
- About page
- Contact page
- Shipping policy
- Return policy

4. Create first product listing.

5. Review pricing.

6. Test product page manually.

7. Create first content drafts.

### End Of Week Goal

Have:
- first live-ready product
- storefront functioning
- content ready to post

## Week 3 — Content Testing

### Goals

- Start posting consistently
- Learn what gets attention

### Tasks

1. Post manually.

2. Try different post styles.

3. Track:
- views
- comments
- shares
- clicks

4. Reply to comments.

5. Improve weak posts.

6. Make more variations of stronger designs.

### End Of Week Goal

Understand:
- what people react to
- which designs get attention
- which content formats work best

## Week 4 — Optimization

### Goals

- Improve workflow
- Improve products
- Improve consistency

### Tasks

1. Review all trackers.

2. Identify:
- best designs
- weak designs
- best posts
- weak posts

3. Improve mockups.

4. Improve descriptions.

5. Create more designs in the strongest category.

6. Continue posting consistently.

### End Of Month Goal

Have:
- a functioning workflow
- organized assets
- active storefront
- real posting habit
- product feedback
- better understanding of the market

## Important Rule

The first month is mostly about learning.

Do not expect:
- instant viral success
- huge profits
- perfect branding
- fully automated systems

Focus on:
- consistency
- iteration
- learning what people respond to
