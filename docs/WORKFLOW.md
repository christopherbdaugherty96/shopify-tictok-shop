# Workflow

## Manual Ecommerce Loop

1. Pick niche or product idea
2. Create design brief
3. Generate or create design
4. Make mockup
5. Draft Shopify product listing
6. Publish manually
7. Draft short-form content
8. Post manually
9. Track sales/content performance
10. Improve design, offer, or content

## Operating Principle

The workflow must work manually before automation is considered.
