# How To Create Designs

The goal of the first designs is testing product ideas quickly.

Do not overcomplicate the process.

## Beginner-Friendly Tools

Start with:
- Canva free
- Photopea
- Kittl free plan

## Simple Design Styles Work Best Initially

Good starting styles:
- bold text
- clean phrases
- niche humor
- simple graphics
- readable typography

## Design Rules

### Rule 1: Readability

People should understand the shirt quickly.

### Rule 2: Strong Contrast

Use colors that are easy to read.

### Rule 3: Keep It Simple

Simple designs often perform better than cluttered designs.

### Rule 4: Avoid Copyright Problems

Do not use:
- sports logos
- celebrity images
- movie/show graphics
- trademarked phrases
- copied designs

## Recommended Workflow

1. Choose niche.
2. Write phrase ideas.
3. Create 3 to 5 rough concepts.
4. Pick the strongest one.
5. Create clean export.
6. Generate mockups.
7. Test through content.

## Exporting

Recommended:
- PNG
- transparent background if possible
- high resolution

## File Organization

Store designs under:

```txt
assets/designs/
```

Keep:
- editable source files
- exported PNGs
- version history if possible

## Important Rule

The first goal is testing reaction.

Do not spend weeks perfecting one design before posting.
