# Start Here

This is the beginner launch order for the business.

Use this repo in order. Do not jump to automation, paid ads, or complicated tools first.

## Goal

Start a print-on-demand shirt business where:

1. You create a design.
2. You make mockups.
3. You post the product online.
4. A customer buys.
5. Printify or Printful prints and ships the order.
6. You never physically touch the shirt.

## Launch Order

### Step 1: Understand the model

Read:

- `docs/CORE_IDEA.md`
- `docs/STARTUP_GUIDE.md`
- `docs/ORDER_FLOW.md`

### Step 2: Set up accounts

Read:

- `docs/APP_STACK_AND_ACCOUNTS.md`

Minimum starting accounts:

- Gmail or dedicated business email
- Canva free
- Printify or Printful
- Shopify when ready to accept orders
- TikTok
- Instagram

### Step 3: Choose the first niche

Read:

- `docs/BRAND_IDENTITY.md`
- `docs/NICHE_RESEARCH.md`

Do not start with random designs for everyone.

Pick one audience first.

### Step 4: Create first product ideas

Use:

- `trackers/design_backlog.csv`
- `templates/design_brief_template.md`

Create 10 ideas before making too many products.

### Step 5: Make 1 to 3 designs

Use Canva, Photopea, or Kittl.

Save files under:

```txt
assets/designs/
```

### Step 6: Create product mockups

Use Printify or Printful mockup generator.

Save mockups under:

```txt
assets/mockups/
```

### Step 7: Draft the product listing

Use:

- `templates/product_listing_template.md`

Do not publish until pricing, shipping, and mockups are checked.

### Step 8: Set up payment and fulfillment

Read:

- `docs/PAYMENT_AND_FULFILLMENT.md`

Make sure Shopify payment and Printify/Printful connection are working before taking real orders.

### Step 9: Post manually

Use:

- `docs/CONTENT_STRATEGY.md`
- `templates/tiktok_post_template.md`
- `templates/instagram_caption_template.md`
- `trackers/content_calendar.csv`

### Step 10: Track sales and improve

Use:

- `trackers/sales_pipeline.csv`
- `trackers/products.csv`

Each week, review what got views, clicks, comments, and sales.

## Rule

The business process comes first.

Automation comes later only after the manual workflow works.
