# Auralis Website Structure

This document explains the recommended structure for the Auralis website.

The website should feel curated, visual, and collection-based.

It should not feel like a random product catalog.

## Website Role

The website is the:
- brand layer
- discovery layer
- visual identity layer
- collection/story layer

Shopify handles commerce infrastructure behind the scenes.

## Recommended Website Structure

```txt
Home
Collections
Apparel
Artwork
Personal Works
About
Contact
Shop Links
```

## Homepage

The homepage should communicate:
- the visual identity
- the mood of the brand
- featured collections
- featured artwork
- featured products

Avoid clutter.

## Collections Page

Collections should organize products by visual identity or mood.

Example collections:

```txt
Abstract Works
Geometric Works
Tie-Dye Colorways
Dark Colorways
Light Colorways
Limited Drops
Personal Works
```

## Apparel Section

This section contains:
- T-shirts
- hoodies
- wearable designs
- made-to-order products

Recommended customer-facing wording:

```txt
made to order
```

or:

```txt
produced after purchase
```

## Artwork Section

This section may contain:
- paintings
- digital artwork
- limited prints
- visual experiments
- personal works

This section should stay curated.

## Product Pages

Each product page should include:
- clean mockups
- collection placement
- short description
- sizing information
- shipping expectations
- buy button/link

## Checkout Flow

Recommended flow:

```txt
Auralis website
→ product page
→ Shopify product or checkout
→ Printify/Printful or manual fulfillment
```

## Important Rule

Do not build a giant catalog immediately.

Start with:
- 3 collections
- 3 to 9 products
- a small artwork section
- strong visual consistency

## Visual Identity Rule

Everything should feel connected.

Even if the collections vary, the website should still feel like:

```txt
one visual world
```

not:

```txt
multiple random stores combined together
```
