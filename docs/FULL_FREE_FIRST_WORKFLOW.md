# Full Free-First Workflow

This is the end-to-end workflow for starting Auralis with the lowest possible cost.

The goal is to create T-shirt designs, prepare products, make product pictures/mockups, advertise manually, accept orders, and fulfill through a provider when possible.

## Core Flow

```txt
Idea
→ design
→ mockup/product pictures
→ product listing
→ store/payment setup
→ manual advertising
→ customer order
→ fulfillment
→ tracking and improvement
```

## Minimum Free-First App Stack

### Design

Use:
- Canva free
- Photopea
- Kittl free plan if needed

Purpose:
- T-shirt designs
- abstract/geometric/tie-dye graphics
- post images
- logo/basic brand assets

### AI Design Help

Use:
- ChatGPT for concepts, prompts, names, captions, product descriptions
- free image/design tools only when available

Human judgment decides final designs.

### Mockups / Product Pictures

Use:
- Printify mockup generator
- Printful mockup generator
- Canva mockup templates

Optional later:
- order a sample shirt and take real photos

### Product Fulfillment

Use one provider first:
- Printify
- Printful

Recommended starting choice:
- Printify for lower-cost testing
- Printful for simpler polished setup

### Storefront / Checkout

Best first serious setup:
- Shopify connected to Printify or Printful

Free/low-cost testing before Shopify:
- post mockups on TikTok/Instagram/Facebook
- test interest before paying for extra tools

### Social Posting

Use:
- TikTok
- Instagram Reels
- Facebook page/profile

Optional later:
- Pinterest
- YouTube Shorts

### Video Editing

Use:
- CapCut free
- Canva free

### Tracking

Use repo CSVs first:
- `trackers/design_backlog.csv`
- `trackers/products.csv`
- `trackers/content_calendar.csv`
- `trackers/sales_pipeline.csv`

Optional later:
- Google Sheets
- Notion
- Airtable

## Step 1: Pick First Collection Direction

Start with one to three lanes only:

```txt
Abstract Works
Geometric Works
Tie-Dye Colorways
```

Do not start with a huge catalog.

## Step 2: Create Design Ideas

Use:
- `trackers/design_backlog.csv`
- `templates/design_brief_template.md`

Create 10 rough ideas.

Track:
- idea name
- audience
- visual style
- product type
- status
- notes

## Step 3: Create First 3 Designs

Create one design per lane:

1. Abstract design
2. Geometric design
3. Tie-dye/colorway design

Use Canva, Photopea, Kittl, or your own artwork.

Export:
- transparent PNG when possible
- high-resolution file
- editable source file saved

Save under:

```txt
assets/designs/
```

## Step 4: Create Product Mockups

Upload the design to Printify or Printful.

Generate mockups:
- front view
- close-up
- lifestyle image if available
- black shirt version
- white shirt version if the design works

Save under:

```txt
assets/mockups/
```

## Step 5: Decide Product Type

Start with one product type:

```txt
T-shirt
```

Avoid adding hoodies, hats, mugs, and accessories too early.

## Step 6: Create Storefront Account

Recommended:

```txt
Shopify + Printify or Shopify + Printful
```

Shopify handles:
- product page
- checkout
- payments
- order emails
- customer info
- order status

Printify/Printful handles:
- production
- printing
- packaging
- shipping
- fulfillment updates

## Step 7: Set Up Payments

Inside Shopify, set up:
- Shopify Payments if eligible
- bank payout account
- identity verification if requested
- PayPal if desired later

Do not advertise heavily until checkout and payment setup are working.

## Step 8: Draft Product Listing

Use:

```txt
templates/product_listing_template.md
```

Each listing needs:
- product title
- collection name
- short product description
- material/product details
- sizing info
- production/shipping expectations
- return/support note
- mockups
- price

Use customer-facing wording like:

```txt
made to order
```

or:

```txt
produced after purchase
```

Do not write:

```txt
I never touch the product
```

That is internal operations language.

## Step 9: Price Product

Use:

```txt
Retail price - product cost - shipping/fees = estimated profit
```

Check:
- product base cost
- shipping
- Shopify/payment fees
- discounts
- refund risk

Do not price too low.

## Step 10: Publish Manually

Before publishing:
- check mockups
- check spelling
- check price
- check shipping info
- check size chart
- check buy button
- check mobile view

Publish only after reviewing manually.

## Step 11: Create Advertising Content

Start with organic content.

Use:
- Canva free
- CapCut free
- mockups
- screen recordings
- artwork process clips

Post types:
- mockup slideshow
- design reveal
- “Would you wear this?”
- collection preview
- artwork-to-shirt transformation
- close-up design detail
- niche/aesthetic mood post

## Step 12: Post Manually

Post on:
- TikTok
- Instagram Reels
- Facebook

Track every post in:

```txt
trackers/content_calendar.csv
```

Track:
- date
- platform
- product
- hook
- views
- likes
- comments
- shares
- clicks
- notes

## Step 13: Handle Orders

When a customer orders:

1. Shopify processes payment.
2. Order appears in Shopify.
3. Order syncs to Printify/Printful.
4. Provider produces the item.
5. Provider ships the item.
6. Tracking updates are sent.
7. You monitor the order.

Review early orders manually.

## Step 14: Customer Support

Use:
- business email
- Shopify contact form
- social DMs if needed

Answer questions about:
- tracking
- sizing
- damaged items
- wrong address
- shipping delays

Do not promise what the fulfillment provider cannot guarantee.

## Step 15: Track Sales

Use:

```txt
trackers/sales_pipeline.csv
```

Track:
- order date
- product
- sale price
- product cost
- fees
- estimated profit
- source of sale
- customer issue
- notes

## Step 16: Improve Weekly

Every week, review:
- best design
- worst design
- best post
- worst post
- strongest collection direction
- customer questions
- sales/profit

Then decide:
- make more of one style
- improve mockups
- improve listing
- post more content
- retire weak designs

## What To Avoid First

Do not start with:
- paid ads
- bulk inventory
- custom checkout
- huge catalog
- multiple unrelated niches
- expensive apps
- automation
- autonomous posting

## First 14-Day Sprint

Day 1: choose 3 visual lanes.
Day 2: create 10 design ideas.
Day 3-4: create 3 designs.
Day 5: create mockups.
Day 6: set up Printify/Printful.
Day 7: draft product listings.
Day 8: set up Shopify basics.
Day 9: check payment/fulfillment setup.
Day 10: create first content batch.
Day 11-14: post manually and track results.

## Success Signals

Look for:
- comments
- shares
- saves
- profile visits
- product clicks
- people asking where to buy
- first sale

Do not judge only by likes.
